隐私政策 / PRIVACY

你的专注，只属于你。

适用版本：1.0 桌面专注版 · 更新及生效日期：2026 年 9 月 8 日

「别让我抓到」是一款离线自我监督工具。开发与支持账号为 w4hongyan，沿用「礼往来」的开发者支持渠道。以下说明 App 实际处理的数据和你拥有的选择。

无需账号，无广告，无第三方统计 SDK。专注任务和运动读数不上传到开发者服务器。

01 / 本地保存哪些信息

你输入的任务名称、开始和结束时间、计划与实际时长、专注模式、完成或中断状态、巡视次数、拿起提醒次数，以及通知、语气、触感等偏好，保存在当前设备的 App 本地目录中，用于计时、统计、恢复会话和展示历史记录。

App 不主动将这些数据同步到开发者服务器。你开启的 Apple 设备备份可能包含本地数据，具体由你的系统备份设置和 Apple 的规则决定。

02 / 运动传感器

桌面监督使用 Core Motion 提供的重力方向与加速度，在本机估算手机是否被拿起。原始读数即时处理，不存储、不上传。仅保存本轮提醒次数。离开前台或结束任务时停止运动检测。

App 不申请摄像头、麦克风、通讯录或位置访问，不识别人脸，不读取屏幕内容。运动判断是启发式提醒，不证明用户在使用其他应用或处于何种学习状态。

03 / 可选通知

仅当你主动打开“结束时通知我”时请求系统通知权限。提醒由本机按截止时间安排，不依赖开发者推送服务器。通知可能显示任务名称，请根据需要在 iPhone 系统设置中调整锁屏预览。你可随时关闭提醒，计时功能仍正常运行。

04 / 导出、保留与删除

在 App 的“设置 → 导出本地记录”中生成 JSON 快照，再使用系统分享面板选择存储位置或接收方。文件包含任务名称等完整记录和偏好，请在分享前检查内容。App 会暂存待分享文件，系统可能清理临时文件；清除 App 数据时也会清理该临时副本。

本地记录保留至你在“设置 → 清除专注记录与偏好”中确认清除，或删除 App 数据。清除后没有撤销操作，1.0 暂无记录导入功能。你此前自行导出的文件和系统备份不随 App 内清除操作删除，请到相应位置单独管理。

记录读取异常时，App 保留原文件，并提供导出诊断文件与确认重置入口；诊断文件只在你主动分享时交给接收方。

05 / 网络页面与反馈

核心功能无需联网。你主动打开外部支持页面、GitHub Issues 或 App Store 时，会离开 App 的本地功能范围，相应网站按自身政策处理网络访问和你提交的内容。本支持网站由 GitHub Pages 托管，不加载第三方统计脚本、广告或远程字体；托管方可能处理提供网站服务所需的连接信息。

如通过 TestFlight 主动反馈，Apple 会按其机制向开发者提供相应反馈或诊断信息。开发者仅使用你主动提交的内容处理问题。GitHub Issues 为公开讨论区，请勿上传未经处理的任务记录、电话号码或其他敏感信息。

06 / 版本范围与更新

1.0 桌面专注版不屏蔽其他应用，不含账号、内购、订阅、云同步或聊天功能。将来如开放系统应用限制或新增数据处理方式，会同步更新对应版本的说明和本政策。

本工具不要求输入年龄或身份信息。请避免在任务名称和公开反馈中填写个人敏感信息；未成年人遇到分享或隐私问题时，建议由监护人协助处理。
